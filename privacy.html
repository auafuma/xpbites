Privacy Policy

Last updated 29 October 2026

This website

This website has no sign-up, no cookies, no analytics and no tracking. The site is hosted on GitHub Pages; GitHub may keep standard server logs such as IP addresses, under the GitHub Privacy Statement.

XP Bites Publisher

XP Bites Publisher only connects to accounts owned by XP Bites. When we connect our TikTok account, TikTok gives the tool:

  • an access token and refresh token, so it can post our approved videos;
  • the account's open ID and basic profile information (username, display name), so we can confirm which account we are posting to.

The tool uses this only to post XP Bites videos and to check their posting status. The tokens are stored on our own server in a file only the administrator account can read, and are never sold or shared with anyone. We do not collect data about viewers or other TikTok users.

Removing access

We can remove the tool's access at any time from TikTok's settings (Security and permissions, then Manage app permissions). Deleting the tokens from our server ends all access.
